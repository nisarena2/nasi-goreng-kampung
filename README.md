# Nasi Goreng Kampung

A professional food photograph of Indonesian nasi goreng kampung served on a banana leaf in a clay plate: glossy wok-fried rice topped with a sunny-side-up egg whose runny golden yolk is dripping, chicken satay skewers with peanut sauce, crispy kerupuk, red sambal, and fresh cucumber and tomato, with steam rising from the plate.

The image is 1024x1024 and under 1 MiB.

## Run it

mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
