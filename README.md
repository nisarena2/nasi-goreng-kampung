# Mie Ayam — Tall Noodle Pull

A professional food photograph of Indonesian mie ayam: a tall lift of glossy
golden egg noodles rising from a dark bowl of steaming chicken broth, a halved
jammy egg with its yolk dripping, shredded chicken, fried shallots and spring
onion scattered on top, steam curling up in warm light.

## Run it

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` into the output directory.

The image is 1024x1024 and under 1 MiB.
